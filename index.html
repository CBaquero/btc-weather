How to read this report
  • Mempool — valid transactions waiting to be mined. Miners take the best-paying ones for the next block, roughly every 10 minutes.
  • sat/vB — fee rate in satoshis per virtual byte. A higher rate gets picked sooner.
  • Forecast — the mempool sorted into blocks the way this node would mine it now. New arrivals that pay more will jump the queue, so later blocks are less certain.
  • Queue position — how many blocks of better-paying weight sit ahead of a fee band. "Next block" means a tx at that rate would fit right now.
  • Monetary / inscription / data — a heuristic from script types and witness sizes: monetary txs move BTC; data txs mainly carry payloads (OP_RETURN, protocols).
  • Whale — a single pending tx moving at least 100 BTC.
