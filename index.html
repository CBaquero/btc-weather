How to read this report
  • Mempool — the queue of valid transactions waiting to be mined. Miners pick from here to fill the next block (~10 min).
  • sat/vB — fee rate in satoshis per virtual byte. Higher = faster confirmation. Numbers below ~1 sat/vB usually wait a long time.

  • Whale — a single pending tx moving ≥100 BTC.
  • Public JSON — same data at /data.json.
